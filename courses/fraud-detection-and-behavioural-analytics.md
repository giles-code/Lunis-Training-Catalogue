## Aim and Purpose

The aim of this workshop is to build participants' understanding of how AI-enabled fraud detection systems operate across payments and banking channels, examining behavioural analytics and biometric techniques, and the supervisory considerations for assessing firms' fraud control frameworks.

## Intended Audience

Mid-level supervisory and financial crime specialist staff assessing firms' financial crime controls.

## Learning Objectives

- Explain how real-time fraud scoring systems operate
- Describe behavioural biometric techniques used in fraud detection
- Assess common payment fraud typologies
- Evaluate the adequacy of a firm's fraud control framework
- Identify supervisory considerations for assessing fraud detection effectiveness

## Syllabus

**Session 1: Real-time fraud scoring (09:30–10:45)**
*Objective: Explain real-time fraud scoring systems*
- How real-time fraud scoring works across payment channels
- Data inputs: transaction, device, behavioural signals
- Speed versus accuracy trade-offs in real-time decisioning
- Regulatory expectations for fraud control frameworks
Activities:
- Facilitated discussion: fraud typologies observed by participants

**Session 2: Behavioural biometrics and typologies (11:00–12:30)**
*Objective: Describe behavioural biometrics and assess fraud typologies*
- Behavioural biometric techniques: typing patterns, device handling
- Common payment fraud typologies: APP fraud, account takeover, card fraud
- Strengths and limitations of biometric fraud detection
- Privacy considerations in behavioural biometrics
Activities:
- Group exercise: map fraud typologies to appropriate detection techniques

**Session 3: Evaluating fraud control frameworks (13:30–14:45)**
*Objective: Evaluate a fraud framework and identify supervisory considerations*
- Criteria for assessing fraud control framework adequacy
- Case study: a firm's fraud control framework under review
Activities:
- Case study: evaluate a firm's fraud control framework and identify supervisory considerations

**Session 4: Wrap-up and key takeaways (14:45–15:00)**
*Objective: Consolidate learning*
- Recap: fraud scoring, biometrics, typologies, framework assessment
Activities:
- Reflection and discussion
- Q&A

## Structure and Format

Proposed as a half-day workshop (approx. 3.5 hours substantive content), comprising 4 sessions:
- Session 1: Real-time fraud scoring (09:30–10:45)
- Session 2: Behavioural biometrics and typologies (11:00–12:30)
- Session 3: Evaluating fraud control frameworks (13:30–14:45)
- Session 4: Wrap-up and key takeaways (14:45–15:00)

**Key Takeaways**
- Fraud detection increasingly relies on behavioural signals as much as transaction data
- Speed and accuracy trade-offs in real-time fraud decisioning have direct consumer impact
- A strong fraud control framework combines technology, process, and clear escalation routes
