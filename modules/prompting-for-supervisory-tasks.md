## Aim and Purpose

How to write clear, structured prompts that give AI tools the role, context, task and output format they need, and how to refine prompts until results are dependable.

## Learning Objectives

- Structure prompts using role, context, task, constraints and format
- Refine outputs through iteration, examples and follow-up questions
- Build a reusable prompt library for common supervisory tasks

## Syllabus

- Anatomy of a good prompt and common prompting mistakes
- Grounding the tool in source documents rather than its general knowledge
- Step-by-step reasoning, checklists and structured outputs
- Exercise: building team prompt templates
