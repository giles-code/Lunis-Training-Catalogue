## Aim and Purpose

The aim of this workshop is to build participants' understanding of the data and case-management infrastructure that underpins risk-based supervision, and to develop practical skills for evaluating and improving that infrastructure across functions.

## Intended Audience

Mid-to-senior staff involved in the authority's own data and technology infrastructure.

## Learning Objectives

- Explain the role of data infrastructure in risk-based supervision
- Describe the components of a supervisory case-management system
- Assess data integration challenges across supervisory functions
- Evaluate the strengths and weaknesses of a sample data architecture
- Identify priorities for improving supervisory data infrastructure

## Syllabus

**Session 1: Data infrastructure and risk-based supervision (09:30–10:45)**
*Objective: Explain why data infrastructure underpins effective supervision*
- The link between data quality and supervisory judgement
- Core components: case management, risk scoring, document repositories
- Common data infrastructure failure modes
- Data infrastructure maturity models
Activities:
- Facilitated discussion: how data gaps have affected participants' own supervisory work

**Session 2: Integration challenges across functions (11:00–12:30)**
*Objective: Assess data integration challenges across functions*
- Why data silos form between authorisation, supervision and enforcement
- Integrating financial crime, prudential and conduct data
- Data standards and taxonomies
- The cost of poor integration: duplicated effort, missed risk signals
Activities:
- Group exercise: map data flows across a sample authority's functions and identify silos

**Session 3: Evaluating and improving infrastructure (13:30–14:45)**
*Objective: Evaluate a sample architecture and identify improvement priorities*
- Evaluating a data architecture against maturity benchmarks
- Prioritising improvements given resource constraints
- Build versus buy considerations
- Case study: a sample authority's data infrastructure
Activities:
- Case study: evaluate a sample architecture and propose a prioritised improvement plan

**Session 4: Wrap-up and key takeaways (14:45–15:00)**
*Objective: Consolidate learning*
- Recap: infrastructure components, integration, prioritisation
Activities:
- Reflection and discussion
- Q&A

## Structure and Format

Proposed as a half-day workshop (approx. 3.5 hours substantive content), comprising 4 sessions:
- Session 1: Data infrastructure and risk-based supervision (09:30–10:45)
- Session 2: Integration challenges across functions (11:00–12:30)
- Session 3: Evaluating and improving infrastructure (13:30–14:45)
- Session 4: Wrap-up and key takeaways (14:45–15:00)

**Key Takeaways**
- Data infrastructure is not a back-office concern — it directly shapes the quality of supervisory judgement
- Data silos between functions are a common and costly failure mode
- Improvement should be prioritised against maturity gaps, not pursued for its own sake
