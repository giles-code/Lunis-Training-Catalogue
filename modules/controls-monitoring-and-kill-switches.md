## Aim and Purpose

The control environment for agents that act: pre-deployment testing, guardrails, real-time monitoring, human intervention and the ability to stop an agent quickly.

## Learning Objectives

- Design layered controls and guardrails for agentic systems
- Specify monitoring, logging and alerting for agent behaviour
- Implement and test kill-switches and human override

## Syllabus

- Testing, red-teaming and staged deployment
- Guardrails, hard limits and tool restrictions
- Real-time monitoring, audit trails and anomaly detection
- Kill-switches, rollback and incident response
