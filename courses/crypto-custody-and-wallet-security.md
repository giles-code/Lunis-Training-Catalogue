## Aim and Purpose

The aim of this workshop is to build participants' understanding of the technical and operational considerations in crypto-asset custody, including private key management, storage architecture, and how supervisors can assess a firm's custody control framework and proof-of-reserves practices.

## Intended Audience

Mid-level supervisory staff building capability in digital assets/crypto-asset regulation.

## Learning Objectives

- Explain private key management and its centrality to crypto custody
- Describe cold, hot and warm storage architectures
- Assess the adequacy of a firm's multi-signature and access controls
- Evaluate proof-of-reserves practices for credibility
- Formulate a supervisory assessment of a firm's custody control framework

## Syllabus

**Session 1: Private key management fundamentals (09:30–10:45)**
*Objective: Explain private key management*
- Why private key control equals asset control in crypto custody
- Key generation, storage, and backup practices
- Risks of key loss, theft, and single points of failure
- Custody models: self-custody, third-party custody, hybrid
Activities:
- Facilitated discussion: custody incidents participants are aware of

**Session 2: Storage architecture and access controls (11:00–12:30)**
*Objective: Describe storage architecture and assess access controls*
- Cold, hot and warm storage: trade-offs between security and operational access
- Multi-signature and threshold signature schemes
- Assessing access control governance: who can authorise a transaction
- Common custody control weaknesses
Activities:
- Group exercise: assess a sample firm's storage architecture and access controls

**Session 3: Proof of reserves and application (13:30–14:45)**
*Objective: Evaluate proof-of-reserves practices and formulate an assessment*
- What credible proof-of-reserves practice requires
- Limitations of common proof-of-reserves approaches
- Case study: a custody control framework under supervisory review
Activities:
- Case study: formulate a supervisory assessment of a firm's custody control framework

**Session 4: Wrap-up and key takeaways (14:45–15:00)**
*Objective: Consolidate learning*
- Recap: key management, storage architecture, proof of reserves
Activities:
- Reflection and discussion
- Q&A

## Structure and Format

Proposed as a half-day workshop (approx. 3.5 hours substantive content), comprising 4 sessions:
- Session 1: Private key management fundamentals (09:30–10:45)
- Session 2: Storage architecture and access controls (11:00–12:30)
- Session 3: Proof of reserves and application (13:30–14:45)
- Session 4: Wrap-up and key takeaways (14:45–15:00)

**Key Takeaways**
- In crypto custody, control of private keys is functionally equivalent to control of the underlying assets
- Storage architecture choices involve a genuine trade-off between security and operational accessibility
- Proof-of-reserves claims vary hugely in credibility and should be assessed critically, not taken at face value
