## Aim and Purpose

Core methods for turning reports and data into actionable intelligence on specific targets, including link and network analysis, flow-of-funds analysis and the development and testing of hypotheses.

## Learning Objectives

- Apply link, network and flow-of-funds analysis to case data
- Develop and test hypotheses about suspected criminal activity
- Evaluate source reliability and grade intelligence consistently

## Syllabus

- The analytical process: collation, evaluation, analysis and inference
- Link charts, network analysis and timelines
- Flow-of-funds and transaction pattern analysis
- Hypothesis testing, cognitive bias and source grading
