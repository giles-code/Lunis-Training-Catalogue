## Aim and Purpose

The risk-based testing programme every in-scope entity must run, and the threat-led penetration testing required of selected entities, including scoping, testers, cross-border recognition and supervisory follow-up.

## Learning Objectives

- Design a proportionate digital operational resilience testing programme
- Explain which entities must perform TLPT and how it is scoped and run
- Assess test findings, remediation and the attestation process

## Syllabus

- Testing toolkit: vulnerability assessments, scenario tests and source code reviews
- TLPT identification, scope, threat intelligence and red team phases
- Internal and external testers, pooled testing and mutual recognition
- Red flags: narrowed scope, repeat findings and slipping remediation
