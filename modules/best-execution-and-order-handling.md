## Aim and Purpose

How firms take all sufficient steps to obtain the best result for clients, handle and allocate orders fairly, and monitor execution quality.

## Learning Objectives

- Design an execution policy and venue selection process
- Implement fair order handling, aggregation and allocation
- Monitor execution quality and act on the results

## Syllabus

- Execution factors, execution policy and client disclosure
- Order handling, aggregation and fair allocation
- Execution monitoring, transaction cost analysis and best execution committees
- Payment for order flow and conflicts in order routing
