## Aim and Purpose

The aim of this workshop is to build participants' understanding of how regulated entities use AI and machine learning to strengthen transaction monitoring and suspicious activity detection, and the practical trade-offs supervisors should expect firms to manage.

## Intended Audience

Mid-level supervisory and financial crime specialist staff assessing firms' financial crime controls.

## Learning Objectives

- Explain how AI/ML techniques are applied to transaction monitoring
- Describe network and graph analytics approaches to detecting suspicious activity
- Assess the trade-off between detection sensitivity and false-positive rates
- Evaluate a firm's AI-driven monitoring system for supervisory adequacy
- Identify the human oversight controls that should accompany AI-driven detection

## Syllabus

**Session 1: AI/ML in transaction monitoring (09:30–10:45)**
*Objective: Explain AI/ML applications in transaction monitoring*
- From rules-based to AI/ML-driven transaction monitoring
- Anomaly detection and behavioural profiling techniques
- Network and graph analytics for detecting suspicious patterns
- Realistic capabilities and limitations of current AI/ML tools
Activities:
- Facilitated discussion: AI adoption in AML systems participants have encountered

**Session 2: False positives and detection trade-offs (11:00–12:30)**
*Objective: Assess the sensitivity/false-positive trade-off*
- Why false-positive rates matter for both firms and supervisors
- Techniques for false-positive reduction and their risks
- The risk of tuning systems to minimise workload rather than maximise detection
- Assessing model performance metrics critically
Activities:
- Group exercise: assess a sample AI monitoring system's performance metrics

**Session 3: Supervisory assessment and oversight (13:30–14:45)**
*Objective: Evaluate AI monitoring systems and identify oversight controls*
- Supervisory criteria for assessing AI-driven monitoring adequacy
- Human oversight and escalation controls that should accompany AI detection
- Case study: a firm's AI monitoring system under supervisory review
Activities:
- Case study: evaluate a firm's AI-driven monitoring system and identify oversight gaps

**Session 4: Wrap-up and key takeaways (14:45–15:00)**
*Objective: Consolidate learning*
- Recap: AI/ML techniques, false-positive trade-offs, oversight
Activities:
- Reflection and discussion
- Q&A

## Structure and Format

Proposed as a half-day workshop (approx. 3.5 hours substantive content), comprising 4 sessions:
- Session 1: AI/ML in transaction monitoring (09:30–10:45)
- Session 2: False positives and detection trade-offs (11:00–12:30)
- Session 3: Supervisory assessment and oversight (13:30–14:45)
- Session 4: Wrap-up and key takeaways (14:45–15:00)

**Key Takeaways**
- AI/ML-driven monitoring changes the nature of supervisory review — from checking rules to assessing model performance
- Reducing false positives is only beneficial if genuine detection capability is preserved
- Human oversight remains essential even in highly automated detection systems
