## Aim and Purpose

The aim of this workshop is to build participants' skills in supervising firms' best execution and client order handling practices, including assessing execution quality monitoring and reporting.

## Intended Audience

Junior to mid-level supervisors working in investment services/capital markets supervision.

## Learning Objectives

- Explain the best execution obligation and its rationale
- Describe order handling rules and their practical application
- Assess a firm's execution quality monitoring framework
- Evaluate execution quality reporting for adequacy and transparency
- Formulate a supervisory assessment of a firm's best execution practice

## Syllabus

**Session 1: Best execution fundamentals (09:30–10:45)**
*Objective: Explain best execution and order handling rules*
- The best execution obligation: what it requires and why
- Order handling rules: fair treatment, aggregation, allocation
- Execution factors: price, cost, speed, likelihood of execution
- Common best execution failures
Activities:
- Facilitated discussion: best execution challenges participants have encountered

**Session 2: Execution quality monitoring (11:00–12:30)**
*Objective: Assess execution quality monitoring frameworks*
- What good execution quality monitoring looks like
- Data and analytics used to monitor execution outcomes
- Assessing whether monitoring drives genuine improvement
- Common monitoring framework weaknesses
Activities:
- Group exercise: assess a sample execution quality monitoring framework

**Session 3: Reporting and application (13:30–14:45)**
*Objective: Evaluate reporting and formulate an assessment*
- Execution quality reporting requirements and transparency expectations
- Assessing whether reporting is meaningful or merely compliant
- Case study: a firm's best execution practice under review
Activities:
- Case study: formulate a supervisory assessment of a firm's best execution practice

**Session 4: Wrap-up and key takeaways (14:45–15:00)**
*Objective: Consolidate learning*
- Recap: best execution obligation, monitoring, reporting
Activities:
- Reflection and discussion
- Q&A

## Structure and Format

Proposed as a half-day workshop (approx. 3.5 hours substantive content), comprising 4 sessions:
- Session 1: Best execution fundamentals (09:30–10:45)
- Session 2: Execution quality monitoring (11:00–12:30)
- Session 3: Reporting and application (13:30–14:45)
- Session 4: Wrap-up and key takeaways (14:45–15:00)

**Key Takeaways**
- Best execution is an ongoing obligation demonstrated through monitoring, not a one-off policy statement
- Execution quality data is only useful if a firm actually acts on what it reveals
- Transparent reporting is both a regulatory requirement and a genuine test of a firm's execution culture
