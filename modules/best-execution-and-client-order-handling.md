## Aim and Purpose

What firms must do to obtain the best possible result for clients, how orders should be handled and allocated fairly, and how supervisors assess execution quality monitoring.

## Learning Objectives

- Explain best execution and client order handling obligations
- Assess execution policies, venue selection and execution quality monitoring
- Identify red flags such as payment for order flow and unfair allocation

## Syllabus

- Execution factors, execution policies and venue selection
- Order handling, aggregation and fair allocation
- Execution quality monitoring and transaction cost analysis
- Payment for order flow and other conflicts in order routing
