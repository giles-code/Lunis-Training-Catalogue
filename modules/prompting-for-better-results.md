## Aim and Purpose

Practical techniques for writing prompts that produce useful, accurate and well-structured outputs for everyday financial services tasks.

## Learning Objectives

- Write clear prompts with context, role, task and format
- Refine outputs through iteration and follow-up instructions
- Build reusable prompts for common work tasks

## Syllabus

- Anatomy of a good prompt: context, task, constraints and output
- Iterating, critiquing and asking the model to check its work
- Prompt patterns for summaries, drafting, comparison and analysis
- Building a personal prompt library
