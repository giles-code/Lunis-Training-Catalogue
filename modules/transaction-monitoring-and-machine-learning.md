## Aim and Purpose

How rules-based and machine learning approaches to transaction monitoring work, what they can realistically achieve, and how to tune, test and combine them to improve detection rather than just reduce alerts.

## Learning Objectives

- Compare rules-based, machine learning and network analytics approaches
- Evaluate tuning, thresholds and false positive reduction claims
- Design alert handling and investigation workflows that support quality

## Syllabus

- Scenario design, thresholds and below-the-line testing
- Supervised and unsupervised learning, anomaly detection and graph analytics
- False positives versus missed detection: measuring true performance
- Alert triage, case management and AI-assisted investigation
