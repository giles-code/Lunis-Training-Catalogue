## Aim and Purpose

How to diagnose root causes and design remediation that defines the destination, has clear ownership and fixes the underlying control failure rather than the symptom.

## Learning Objectives

- Separate incident, control failure and underlying cause
- Design outcome-focused remediation actions
- Set realistic milestones and accountability

## Syllabus

- Incident, control failure and underlying cause
- Define the destination, not the journey
- Ownership, resourcing and realistic timelines
- Case study: drafting the remediation plan
